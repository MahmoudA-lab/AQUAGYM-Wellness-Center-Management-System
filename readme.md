# AQUAGYM Wellness Center Management System

AQUAGYM is a Java Swing and MySQL desktop application designed to manage a wellness center that includes gym, swimming, physiotherapy, memberships, payments, attendance, and health records.

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- NetBeans
- DBeaver

## Main Features
- Secure LoginFrame
- Main Dashboard with live statistics
- Sidebar navigation
- Members management
- Membership plans management
- Trainers and physiotherapists management
- Pools and rooms management
- Personal training sessions
- Swimming sessions
- Physiotherapy sessions
- Payments tracking
- Attendance tracking
- Health records management
- Full CRUD operations connected to MySQL

## Database
The database schema and sample data are available in the `sql` folder.

## How to Run
1. Open the project in NetBeans.
2. Add MySQL Connector/J to the project libraries.
3. Restore the SQL script from the `sql` folder into MySQL.
4. Update `DBConnection.java` with your database credentials.
5. Run `AppLauncher.java`.
